# 480×320 大屏真实定位导航

> 2026-10-05：本文描述早期独立 GPS / 热点固件。开发板当前已改为手机 BLE 固件；请按《手机蓝牙导航使用说明.md》操作，使用安卓手机定位，无需 GPS 模块或开发板连接热点。

## 已验证的硬件配置

新屏实际通过 ILI9488 兼容初始化点亮。项目使用 `Panel_ILI9488`，不要仅按购买名称切回 ST7796 初始化。屏面型号仍需厂家资料确认。

接线沿用点亮测试：VCC/LED→3V3，GND→GND，CS→10，RESET→14，D/C→9，SDI→11，SCK→12，SDO→15。触摸 SDA4/SCL5/INT6/RST7 暂保持连接；这一版导航尚未提供滑动浏览功能。GNSS TX→17，VCC→3V3。

## 程序

Arduino IDE 打开 `software/wide_screen_nav/wide_screen_nav.ino`。开发板 ESP32S3 Dev Module，Flash 8MB，PSRAM OPI，端口 COM7。凭据复制自已有本地文件，不需重新填写，不要分享 secrets 文件。

横屏左侧显示主路线描边、路线芯、已驶过路段、透视位置箭头及进度弧；右侧显示速度环、转向距离、剩余距离、卫星数和热点状态。路线来自高德道路规划，没有虚构周边路网。本版暂不包含道路底图、触摸浏览及完整路网。

目的地仍为洛阳应天门。使用的是高德驾车规划，课堂演示可以验证道路折线；实际电动车使用前需适配骑行路线，不能假定驾车路线适合电动车。

## 使用

1. 天线陶瓷面朝上置于室外开阔处。
2. iPhone 开启个人热点、最大兼容性，保持热点设置页面直到连接完成。
3. 先看 WAIT 页面：卫星数和 HDOP、Wi-Fi 状态会更新。
4. 获得新鲜定位、热点连接及网络时间后，自动请求路线。
5. 无定位时速度显示 --，不会模拟移动或伪造进度。
6. 串口 115200。r 重新规划，p 输出本地坐标（含真实位置，分享日志前删除）。

SPI 初版 4MHz、三字节像素传输，刷新目标约每秒一次，实际受绘制和传输时间限制。若重新白屏，应先退回已验证的 1MHz 再检查，不应贸然改供电电压。
