# 安卓高德直连版 0.4：电动车路线、双端周边底图与配色

手机通过 HTTPS 直接访问高德 Web 服务：地点搜索、候选电动车骑行路线和偏航重规划。路线解析在手机执行，再由原有蓝牙协议发送到 ESP32 屏幕。
不再依赖电脑网关、Cloudflare、自有域名、R2 或 USB 转发。手机仍需要能访问高德的网络。

## 安装和配置

1. 安装 `software/android_nav/output/nav-screen-ebike-map.apk`（`nav-screen-amap-direct.apk` 为同一新版的兼容文件名），覆盖原来的“导航屏助手”。包名和签名沿用原版，不需要卸载或清空数据。
2. 打开“我的”，点击“开启会话 / 授予权限”。
3. 点击“配置 Key / 测试高德连接”，输入自己已有的高德 **Web服务** 类型 Key。不是安卓 SDK Key，也不是 Cloudflare 令牌或网关网址。
4. 保存并测试。验证会向高德搜索公开地点“北京站”，不使用私人位置；成功说明网络和搜索接口可用，路线权限还需要实际规划验证。
5. 手机定位、蓝牙开启后，在“设备”连接 `MOTO GPS TFT`。到室外取得新鲜有效定位，搜索目的地、选择路线并开始导航。
6. 开发板可使用充电宝连接 USB 供电，手机无须连接电脑。

Key 通过 Android 原生密码对话框输入，使用 Android Keystore 的 AES-GCM 加密保存在应用私有数据中，不写入 WebView、源码、APK 或日志。
重新配置时留空可沿用已保存 Key。卸载应用会清除配置。旧版网关地址不再使用。

## 功能边界

- 保留地点搜索、路线选择、转向和剩余距离、手机定位速度、偏航重规划、语音、蓝牙及车辆 GPS 功能。
- 默认使用高德 `v5/direction/electrobike` 电动车骑行接口，首次规划和偏航重规划共用同一接口。请求最多 3 条路线，实际条数由高德返回；接口失败不会回退到驾车或演示路线。按高德电动车算路考虑限行，现场标志、临时管制和车辆类别仍需骑行者确认。
- 手机直接访问 OpenFreeMap 的公开矢量瓦片服务，显示 OpenStreetMap 周边道路、建筑轮廓与路名。瓦片转换到 GCJ-02 后与高德路线叠加。高德 Key 不发送给底图服务。
- 导航屏通过现有蓝牙矢量地图协议接收周边道路，不需要改动现有固件。根据道路密度自动选择 ±500／400／300／200 米的范围，范围内保留全部道路；当前屏幕底图传送道路，建筑轮廓显示在手机端。诊断页显示道路数量及设备确认状态。
- 当前视野瓦片在应用私有缓存中保留 7 天，手机和屏幕共享缓存；换到未缓存区域需要网络，缓存不等于全区域离线地图。底图失败有独立提示，不影响高德接口独立规划路线。
- 首次配置测试25秒未完成会明确提示超时；失败不会回退到演示数据。
- 个人设备直连使用。高德账号仍须具有对应接口权限/配额；仅允许固定服务器IP的 Key 不适用于不断变化的手机出口IP。

- 原生选色弹窗将主路线由 `#00FFFF` 改为 `#2789FF`，手机导航实际绘制蓝色路线；设备设置回读匹配。结束应用进程后独立检查持久配置通过，随后恢复原有青色，其余自定义颜色保留。
- Key 密文持久保存及解密检查通过，测试不输出 Key。APK 编译、签名验证通过。
- 室外行进、实际限行路段、偏航重规划和长时间锁屏导航仍需路测。

## 导航配色

进入“设备 → 导航显示”：

1. 点击主题、车辆图标，或点击颜色块打开原生选色弹窗。可使用预设颜色，也可输入 `#RRGGBB`。
2. 点击“应用”，手机地图、导航数字和预览立即更新，并自动保存到手机。浅色数字会加描边，便于在浅色界面识别。
3. 连接屏幕后点击“同步到设备”；出现“导航配色已同步到设备”表示设备设置已读取回来且与发送值一致。
4. 再次连接屏幕时会自动同步手机已保存的配色。手机端保存不要求蓝牙在线。

## 0.8：保留 Wi-Fi 上网的高德 App 投屏

1. 手机保持现有 Wi-Fi 上网，打开个人热点／WLAN 共享，热点频段选择 2.4GHz。
2. App 设备页连接屏幕蓝牙。在“我的”点“配置屏幕连接手机热点”，将个人热点名称和密码输入原生弹窗；不要填写原上网 Wi-Fi 的凭据。密码经加密 BLE 发给屏幕，不进入网页或日志。
3. 等待“屏幕已连接手机热点，可以开始投屏”，点“地图放大投屏（铺满屏幕）”或“完整画面投屏（保持比例）”，按 Android 提示共享高德 App。每次新投屏会话需要系统授权。
4. 手机不用连接 MOTO SCREEN。停止投屏后，蓝牙导航仍可使用。自定义配色属于蓝牙导航模式；高德 App 投屏画面配色由高德 App 本身控制。

当前 ESP32-S3 不支持手机传统蓝牙 PAN 网络共享。此前 0.6 已验证图像帧接收；0.8 热点网络及流畅度需在配置后继续实测。


## 0.14 推荐投屏方式：Wi-Fi Direct

这台手机的普通个人热点可能跟随5GHz上网Wi-Fi，屏幕只能接入2.4GHz。当前已验证的替代方式：

1. 保持原上网Wi-Fi；导航App开启会话并连接屏幕蓝牙。
2. 在“我的”点“Wi-Fi Direct 投屏网络（保留上网Wi-Fi）”，等待屏幕接入。无需开启系统个人热点。
3. 点“地图放大投屏（铺满屏幕）”，按Android系统提示只共享高德地图。新版识别蓝色导航箭头并跟随裁剪；完整画面模式保留等比显示。

屏幕固件固定40MHz并启用DMA，80MHz实测花屏，已回退。Wi-Fi Direct支持与并发能力因手机而异；本机已验证5GHz上网与2.4GHz直连并存。图像裁剪不提高手机GPS精度。


## 0.15 简洁界面

安装包统一为 `software/android_nav/output/nav-screen.apk`。

- “设备 → 连接显示屏”：自动开启连接、请求所需权限并搜索屏幕。
- “设备 → 导航配色”：修改路线颜色与车辆图标，点击同步显示设置。
- “设置 → 高德地图”：管理本机加密保存的Key。
- “设置 → 高德投屏”：先建立投屏连接，再选择地图跟随/完整画面并开始投屏。
- 诊断信息与许可说明折叠收纳，不影响正常使用。

当前固定使用已恢复正常的40MHz屏幕固件，暂不继续调整帧率。


## 0.16 两种导航方式

整体底部四个栏目保留。进入“导航”后选择：

- **高德蓝牙导航**：确认高德 Web 服务 Key，连接显示屏蓝牙。高德服务验证通过且蓝牙握手成功后，“开始规划路线”可用，随后搜索目的地、选择电动车路线并导航。Key 继续加密保存在手机；导航配色仍在设备页修改。
- **高德投屏导航**：先连接显示屏蓝牙，再点“建立投屏连接”。蓝牙只用于下发 Wi-Fi Direct 网络配置；画面由 Wi-Fi Direct 传输。屏幕取得直连地址后，“开始投屏导航”可用，选择地图跟随或完整画面，按 Android 提示共享高德地图，然后在高德 App 中导航。无需配置高德 Key，也无需手动开启系统个人热点。

切入高德蓝牙导航会停止投屏并关闭直连组。手机上网 Wi-Fi 保持原有方式。开始投屏需要 Android 系统授权，App 无法代替用户确认。

本轮仅分开连接入口并修正连接就绪状态判断；保持已恢复正常的40MHz屏幕固件与现有投屏参数。
