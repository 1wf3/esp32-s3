# 手机导航 HTML 调试版

从项目根目录打开 `output/previews/手机导航实机调试.html`，点击「开始演示」。不需要安装依赖，也不需要 GPS 模块。演示使用项目上游的济南公开测试路线；位置、速度为模拟数据。

可以调节进度和播放倍速、暂停、前进 100 米、模拟定位丢失，并查看手机界面、大屏预览与协议快照。大屏预览是浏览器绘制，不能代替实际屏幕联调。默认不向真实设备发送模拟导航；需要时手动勾选 DEMO 发送选项。

## 红米手机预览

把 HTML 文件复制到手机，用 Chrome 打开。部分文件管理器的内置预览不执行脚本，出现空白时改用 Chrome。

也可以在电脑项目目录运行：

```powershell
node .\software\web_debug\serve.cjs
```

电脑访问 `http://127.0.0.1:8765/phone`。手机与电脑连接同一 Wi-Fi 后，访问 `http://电脑局域网IP:8765/phone`。普通局域网 HTTP 用于界面演示，真实蓝牙与定位需要安全来源。此服务器只提供调试 HTML 和已生成的测试 APK，不提供项目其他文件。

## USB 实机蓝牙与定位调试

手机开启 USB 调试并允许这台电脑连接，在项目目录运行：

```powershell
& '.\build\android_tools\sdk\platform-tools\adb.exe' devices
& '.\build\android_tools\sdk\platform-tools\adb.exe' reverse tcp:8765 tcp:8765
& '.\build\android_tools\sdk\platform-tools\adb.exe' reverse tcp:8787 tcp:8787
```

手机 Chrome 打开 `http://127.0.0.1:8765/phone`。在设置页切换「真实连接模式」，请求手机定位，填写网关地址 `http://127.0.0.1:8787/` 并测试。导航网关需另行启动、配置实时高德模式，并将 `WEB_ORIGIN` 设置为 `http://127.0.0.1:8765`；高德 Key 只放网关。

在设备页连接已烧录手机 BLE 导航固件的屏幕，允许浏览器蓝牙权限，再搜索目的地、选择路线并开始导航。网页不会在定位或网关失败时自动用演示数据顶替。

本版是前台调试页面，锁屏与后台持续导航请用原生安卓应用。浏览器蓝牙和手机定位尚未在你的红米手机上验证，屏幕固件也需要实际烧录联调。

## 源码与检查

模板：`software/web_debug/phone_debug.template.html`；生成命令：`powershell -File software/web_debug/build.ps1`；协议与导航计算检查：`node software/web_debug/test.cjs`。

原生安卓测试包：`software/android_nav/output/nav-screen-android-test.apk`。手机 BLE 固件：`software/phone_ble_nav/`。它们与原先独立 GPS 方案分别保存在不同目录。
