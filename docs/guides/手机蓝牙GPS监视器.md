# 手机蓝牙 GPS 监视器（0.17）

开发板通过独立、加密的 BLE 只读特征提供 GPS 诊断计数。开发板用移动电源或车辆端稳定电源供电后，手机在蓝牙范围内即可查看，不必连接电脑。此功能显示 GPS 诊断摘要，并不转发所有 Serial 输出，也不接收串口命令。

## 更新与使用

1. 将 `software/phone_ble_nav/phone_ble_nav.ino` 新版固件上传开发板。
2. 执行 `software/android_nav/install_phone_test.ps1`，安装 `software/android_nav/output/nav-screen.apk`（版本 0.17）。
3. 在 APP 开启会话并连接 MOTO GPS TFT，打开“设备 → 开发板 GPS 监视器 · 蓝牙”。
4. 计数约每 3 秒更新；车辆定位状态使用原有约 2 秒读取通道。导航传输忙时读取可能延后，过期数据会明确标注。
5. 可以暂停记录、清空记录或复制记录。暂停只暂停历史追加，顶部状态继续更新。历史最多 40 条，仅保留在当前页面，复制内容不含经纬度。

## 字段说明

| 字段 | 含义 |
| --- | --- |
| UART | 本次启动以来 GPS 串口累计字符数（32 位） |
| VALID | 车辆 GPS 是否有 15 秒内的有效位置 |
| SAT | 定位报文报告的卫星数，不是可见卫星总数 |
| AGE | 位置年龄；无效标记显示“无有效位置” |
| HDOP | 水平精度因子；无数据时显示横线 |
| PASS / FAIL | NMEA 校验成功 / 失败累计报文数 |
| FIX_SENTENCES | TinyGPSPlus 统计的含定位报文累计数；是否当前有效仍以 VALID 为准 |

计数重启后归零，达到 32 位上限后回绕。PASS 持续增长但没有有效位置，优先检查天线与搜星环境；FAIL 持续快速增长，排查接线、波特率、供电及干扰。累计 FIX_SENTENCES 大于零不能证明当前仍有有效定位。

## 兼容性和协议

原有车辆定位特征 `7e57a004-b50c-4b6a-9c57-40a54e8e1000` 的 20 字节格式保持不变。

新增特征 `7e57a006-b50c-4b6a-9c57-40a54e8e1000`，READ + READ_ENC，固定 20 字节、小端格式：第 0 字节为版本 1，第 1–3 字节为保留 0，第 4、8、12、16 字节分别起始 uint32 UART、PASS、FAIL、FIX_SENTENCES。

新版 APP 连接旧固件时会提示更新固件。若烧录后仍提示不支持，请先断开再连接，让手机重新发现服务。
