## 手机通过 USB 连接电脑

1. 开启手机开发者选项和 USB 调试，用支持数据传输的数据线连接电脑，并允许电脑调试。
2. 在项目目录运行：

```powershell
& '.\software\android_nav\install_phone_test.ps1'
```

脚本只在检测到一个已授权安卓设备时继续，安装测试 APK、打开应用，并设置本次 USB 连接的端口转发。启动应用时会自动填写并保存 `http://127.0.0.1:8787/` 网关地址。不会自动授予定位等权限。

红米若返回 `INSTALL_FAILED_USER_RESTRICTED`，请在手机允许本次安装，并检查开发者选项中的“USB 安装”。测试包也可从手机 `Download/nav-screen-android-test.apk` 打开安装。2026-10-05 已经通过 USB 正常安装成功。

## 手机应用操作

1. 开启手机蓝牙和位置信息。
2. 打开“导航屏助手（测试版）”，点击“开启会话 / 授予权限”，允许精确定位和附近设备权限，按需要允许通知。
3. 点击“扫描蓝牙设备”，选择 `MOTO GPS TFT`，按系统提示配对。
4. 导航服务地址填写 `http://127.0.0.1:8787/`，点击“保存并测试网关”。这是 USB 转发模式下手机访问电脑网关的地址。
5. 在室外开阔处等待有效 GPS 定位，搜索目的地、选择地点，再选择一条路线开始导航。
6. 查看大屏路线、速度、转向距离和剩余距离。定位过期或精度不足时会停止更新有效指引，不会用模拟位置替代。
7. 用“结束导航”停止指引，用“关闭会话”停止定位与蓝牙服务。

蓝牙配对可以在室内测试；真实路线起点需要有效手机定位。新调试包同时请求手机 GPS、融合与网络定位，并显示来源、精度和更新年龄；仅使用精度 ≤50 米且 15 秒内的新鲜位置，不以旧位置或模拟位置代替定位。目的地输入会自动保存在应用中。锁屏后的定位和蓝牙稳定性要在这台红米上单独验证。

## 重启电脑后的网关启动

在 `software/phone_gateway/backend` 目录运行：

```powershell
node --env-file=.env src/server.js
```

网关监听电脑的 `127.0.0.1:8787`。USB 拔掉或手机重启后，需要再次运行安装脚本或 ADB 端口转发；正常外出使用前需将网关部署到可访问的 HTTPS 服务。

HTML 前台演示的使用方法另见 `手机导航实机调试说明.md`。原来的独立 GPS、热点和开发板直连高德方案保留作历史参考。
