# GNSS首次搜星诊断（2026-10-01）

硬件：ESP32-S3 N8R8 + ATGM336H-5N-31；GNSS TX接GPIO17，首次测试从3V3供电。

在Arduino IDE中编译、上传gnss_test成功。串口115200读取结果：

- NMEA数据连续到达，校验错误为0。
- GGA/RMC尚无有效定位；用于定位的卫星数为0。
- 原始报文观察到GPGSV可见卫星数0、BDGSV可见卫星数1（PRN21，信号字段约23；这是当时快照，并非持续测量）。
- GPTXT报告ANTENNA OPEN。

判断：MCU和GNSS的UART数据链路正常，但尚未获得足够的卫星信号完成定位。不能根据串口已通断言GNSS模块供电完全正常。

ANTENNA OPEN是有源天线检测的开路状态；厂家手册说明使用无源天线时也会报告开路，不能单独据此判断插头脱落或天线坏。

待核对：外接天线是有源还是无源、射频插头是否正确扣合、转接板供电说明和实际模块供电。先断电检查插头；需要模块背面和天线连接点清晰照片才能给出后续电压/测试点建议，暂不建议直接改接5V。

原始报文开关已通过串口发送r打开；再次发送r可恢复简洁结果显示。

## 后续结果：定位成功

用户确认此前天线插头未扣到模块背面射频座，随后断电扣合。报文变为ANTENNA OK。移到室外后开始收到多颗GPS/北斗卫星，最终持续输出新鲜FIX位置。

成功时观察到用于定位的卫星约19～21颗，HDOP约0.7，数据年龄约200～230ms，校验错误0。保持3V3供电即可获得定位；此前5V接法灯不亮、UART无数据，原因未测量确认。

已再次发送r关闭原始报文，恢复每秒一行结果。用户可点击监视器右上角双下箭头切换自动滚动，方便暂停查看；本次尝试点击时检测到用户输入，未确认自动滚动已关闭。

这验证了GNSS接收和解析链路，尚未完成真实位置与导航路线的集成。
