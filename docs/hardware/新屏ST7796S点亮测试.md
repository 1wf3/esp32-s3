# 新屏 ST7796S 点亮测试

## 本次配置
照片模块标为4.0英寸，480×320，SPI+电容触摸。
草图：software/st7796_screen_test/st7796_screen_test.ino。
SPI先用10MHz，横屏480×320，不启用Wi-Fi或请求高德。

## 接线
VCC/LED→3V3、GND→GND；CS10、RESET14、D/C9、SDI11、SCK12、SDO15（可不接）。
触摸：CTP_SDA4、CTP_SCL5、CTP_INT6、CTP_RST7；NC不接，SD卡接口不接。
GPS沿用VCC3V3、GND、TX17。
同一条面包板电源轨可分出VCC/LED/GPS供电，不能将5V和3V3接到同一条轨。

## 观察步骤
1. 启动后红、绿、蓝、白、黑每种约0.45秒。
2. 随后黑底测试页：ST7796S SCREEN TEST；下方四个色块，标签和实际颜色应一致，四周有白色边框。
3. 轻触、滑动屏幕，应出现变化的Raw touch坐标。该坐标尚未做横屏方向转换，先用于验证触摸通信。
4. GNSS区域显示NO DATA、WAIT FIX或FIX。室内WAIT FIX不代表供电故障；如果GPS已接好却持续NO DATA，再检查连接和供电。
5. 串口115200，每两秒输出运行秒数、GNSS字节数及触摸I2C地址。运行秒数应连续增长，不应不断回到0。

## 串口操作
输入c回车：重新运行色彩测试。
输入i回车：切换显示反色，用于黑白颠倒诊断。
输入t回车：重新扫描触摸I2C。

## 待验证
真实屏幕颜色、方向、触摸型号及供电稳定性需通过实物观察确认。本程序尝试识别0x38的FT系列兼容触摸或具有有效产品标识的GT911系列，不以照片推定具体触摸芯片。
原圆屏导航工程保留，导航调试处于用户要求的暂停状态。下一步在新屏确认正常后再迁移导航布局。

## 2026-10-03 白屏诊断记录

- 用户确认接线，SDO/MISO 已接 GPIO15。
- 10MHz、1MHz ST7796 初始化均未产生可见画面。
- 在 Arduino IDE 上传诊断固件成功，程序持续运行，GT 触摸地址 0x5D，触摸坐标有变化。
- 显示方向寄存器写入 00 与 40，读回分别为 00 与 80（当前读取存在位对齐差异），证明 SPI 写入能够影响寄存器，不能据此排除供电或屏面问题。
- 0x04 返回 54 80 66 00；0xD3 返回 FF FF FF FF。型号仍未确认，不能仅据此认定卖家发错型号。
- 当前试用 LovyanGFX Panel_ILI9488 初始化、SPI 1MHz、三字节像素传输，保持原接线和 3V3 供电。该配置仅是兼容性测试，等待用户观察画面结果。
- 后续如仍白屏，需获取该模块厂家原理图/初始化例程与额定输入电压，必要时测量模块输入和稳压输出；避免反复无依据修改电压。
