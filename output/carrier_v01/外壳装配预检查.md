2026-10-20。用户目标：沿用已购屏幕和开发板，元件自购手焊，与转接底板放入一个经济的 3D 打印外壳。实物到货后按最终电路图指导焊接、屏幕/GPS 线束接线及分阶段上电。

## 建议结构

从正面到背面：前框固定显示模块 → 屏幕后部及短线束空间 → 转接板与插上的 ESP32 → 底部焊脚/绝缘间隙 → 可拆后盖。

显示器和转接板各用自己的安装柱定位，不能默认两套安装孔重合；固定件不要顶压玻璃或屏幕后元件。可尝试让转接板元件朝后盖，以便检修，但朝向应以实际插头、USB 及天线位置验证，不能仅凭示意定案。

USB 供电口朝外壳边缘，预留插头外形和插拔方向。默认继续使用壳外充电宝供电，不为此版增加壳内电池。J2/J3 应按插入配套插头后的尺寸检查；排线留弯折位置，避免让后盖硬压插座或让线束折在焊点处。

ESP32 天线优先靠近整机上沿/侧边的净空处，避开显示器金属背板及其它金属/铜的近距离覆盖。此前假设天线满足底板净空，不等于加入屏幕和外壳后自动满足。[乐鑫整机布局说明](https://docs.espressif.com/projects/esp-hardware-design-guidelines/zh_CN/latest/esp32s3/pcb-layout-design.html)

GPS 原天线另行安排朝天的位置及原射频线的走线；内部无法合理放置时再考虑原天线外置，不能默认它与 ESP32 天线共用空间。

## 尺寸计算原则

若屏幕与底板完全平行、投影居中且无插头伸出：

```text
内腔长 ≥ max(显示模块总长, 转接板长) + 两侧装配余量
内腔宽 ≥ max(显示模块总宽, 转接板宽) + 两侧装配余量
外壳外尺寸 = 内腔尺寸 + 壁厚及外伸固定结构
```

这只是基础包络计算；USB、配套插头、线束、GPS、螺柱及天线净空超出投影时必须另外扩大。

深度按实际装配分层相加：显示模块厚度、层间间隙、转接板装配最大高度、底部焊脚间隙，以及前后壳厚度。若两板间元件面对面，层间间距必须能容纳两侧元件与插头，不能只取其中较高的一侧。

目前不承诺 20/30/40 mm 中任何一个厚度能够装下，先测量和摆放验证。

## 最省返工的验证顺序

1. 量显示模块长、宽、最大厚度及安装孔中心距；记录插座与插头的出线方向。
2. 用 80.01 × 62.23 mm 硬纸片代替底板，在真实显示器背面试放；摆入现有开发板、插头和线缆，测整体包络。
3. 若尚未付款制板，先确认该叠放体积是否能接受；若 PCB 已下单，后续按实际整机包络设计外壳。
4. 在 EDA 3D 页面导出当前 STEP，后续 CAD 中加入显示器及 ESP32 的实际尺寸包络做装配检查。当前 STEP 单独不能验证整机。
5. 首次只打印薄定位框、螺柱孔位样片或局部接头开口样片，验证后再打印完整前后壳。
6. 裸板到货后：检查板 → 焊电阻电容 → 焊插座 → 检查短路 → 分阶段插开发板、接屏幕/GPS → 复测装配高度 → 完成整机试装。

这些是初步布局建议，不是已完成的机械设计或防水/车载耐久验证。
