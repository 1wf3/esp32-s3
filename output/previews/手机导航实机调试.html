红米手机打开方式
  1. 使用 Chrome 浏览器；先用演示模式检查界面。
  2. BLE 和定位需要安全来源：可信 HTTPS，或通过 USB 调试转发后的 localhost。普通局域网 HTTP 适合界面预览。
  3. 真实网关还需允许当前页面来源的 CORS 请求；网页 HTTPS 与网关 HTTPS 保持一致。
  4. 屏幕固件、蓝牙权限、定位权限都准备好后，在设备页连接。
