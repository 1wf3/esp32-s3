# Renderer preview

Startup/connection preview: run `software/phone_ble_nav/tests/run_tests.cmd`, then `python software/phone_ble_nav/tests/renderer_preview/build_startup_preview.py` from the project root. Open `output/previews/开机与手机连接预览.html`. It embeds frames generated by the production renderer and includes boot replay and all connection states. The host startup test verifies boot cancellation, timer wrap, idle partial updates and return from navigation. Optional browser QA: set `NODE_PATH` to a directory containing Playwright and run `node software/phone_ble_nav/tests/renderer_preview/capture_startup_preview.cjs` (uses installed Microsoft Edge).

Optional animated GIF: run the capture script with `--gif`, then `python software/phone_ble_nav/tests/renderer_preview/build_startup_gif.py` (Pillow). Output: `output/previews/开机与等待连接动画.gif`.

This preview uses the production PhoneRenderer with a host-only SVG LovyanGFX replacement. The map is parsed from the checked-in real Jinan MVT by the gateway transformer, clipped by the production Java RoadMap and decoded by the production C++ protocol. Navigation facts are the labelled public DEMO fixture.

Run from the repository root: build the Android pure Java tests, compile MakeMap.java into build/android_java_tests, run the public fixture maker and source.mjs, then run MakeMap for build/renderer_preview/roads.txt → map.txt. Combine map.txt and navigation.txt into scene.txt. Compile render.cpp with Visual Studio C++17, include this folder and software/phone_ble_nav/src, and link software/phone_ble_nav/src/ble_protocol.cpp. Run the renderer with scene.txt; its stdout is SVG. The optional second argument stale renders the expired-location state. Do not add this fake LovyanGFX include path to Arduino builds.

Delivery: output/previews/导航屏真实路网效果预览.html and output/previews/导航屏真实路网效果预览.png. The HTML embeds both SVGs, so it works offline.
